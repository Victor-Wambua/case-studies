# Case studies

Write-ups of the systems I build, by **Victor Wambua** (Sir Victor). I'm IT & Systems Manager at Ngong Road Children's Foundation in Nairobi, and I build the systems behind the money: Salesforce (NPSP), payments, finance tools and automation.

The code for these projects is private because it handles real people's money or belongs to clients. This repo shows the work without it. Each study covers the problem, what the system does, how it is built, how it is kept safe, and where it stands. Screenshots use made-up data only.

## How I work

- **Rules written down first.** Every money rule is agreed and numbered before it is coded.
- **Tested, then shipped.** Every change goes through a pull request and CI before it deploys.
- **A record of every change.** Every save is logged, and every change can be traced to who made it and why.
- **Guides for real users.** Each app ships with a plain-language guide that has screenshots, plus a change log.
