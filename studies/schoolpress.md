# SchoolPress

**Status:** live, version 2.14 · **Built with:** WordPress block theme, theme.json, PHP, Full Site Editing

[← All case studies](../README.md)

## The problem

Schools need a website that parents can find their way around, and that staff can update without breaking the design. Most themes give one or the other.

## What it does

- A reusable WordPress block theme for schools, built around a guided Gutenberg editing experience.
- Parent-focused home pages, responsive image layouts, a contact bar on desktop and quick actions on mobile.
- A curated block library and patterns, so staff assemble pages from parts that already fit the design.
- Kahuho Road Academy is the first school to run on it.

## How it was delivered

- Full Site Editing with theme.json, and no page builder.
- Delivered with a website guide for staff, technical documentation and a handover pack.
